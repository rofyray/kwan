# Kwan: words that mark a practice setting as Ghanaian.
#
# Used by the automatic checks (kwan.context.checks): every practice setting must hold at least one
# term from this file. The curriculum pipeline reads the same file to flag Ghanaian exemplars.
#
# Format
#   - One term per line. A term may be several words ("Cape Coast", "tuo zaafi").
#   - A line that starts with "#" is a comment. Blank lines are ignored.
#   - A comment of the form "# [name]" starts a section. Sections are only for people and for
#     reports; a reader that ignores them still gets the full list.
#
# How terms are matched (whole words only)
#   - A term that starts with a capital letter is a name: it must match exactly, capitals included
#     ("Ho" matches "a school in Ho", never "who"). A following 's is allowed ("Ama's").
#   - A term in small letters matches in any case, and also with a plural s or es
#     ("trotro" matches "Trotros", "mango" would match "mangoes").
#
# Rules for editing this file
#   - Add a term only if you are sure it is real and spelled the way Ghanaian schools write it.
#   - If you are not sure, leave it out. A missing term costs nothing; a wrong one teaches an error.
#   - Places sit under their region. Check the region before you add a town.
#   - No brand names, no names of real, known people.
