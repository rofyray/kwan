# Kwan: words that must not appear in a practice setting.
#
# Used by the automatic checks (kwan.context.checks). A setting that holds one of these terms fails
# the "banned" check and cannot be imported from a review sheet.
#
# This list catches the obvious cases only. It does not replace the teacher review: a stereotype or
# an unsafe idea can be written with harmless words, and only a person can see that.
#
# Format
#   - One term per line. A term may be several words.
#   - A line that starts with "#" is a comment. "# [name]" starts a category.
#   - Terms match whole words, in any case ("milo" also catches "Milo").
#   - "=" in front makes the match exact, capitals included. Use it for a brand that is also an
#     everyday word ("=Peak" catches the brand and leaves "the peak of the hill" alone).
#   - "*" at the end matches any ending ("gambl*" catches gamble, gambling, gambler).
#
# Rules for editing this file
#   - Before you add a word, think of the honest sentences that use it. "smoked fish", "sugar cane",
#     "a ludo die" and "she pounds fufu" are all good Ghanaian maths settings.
#   - Brand names: add the product, shop, bank, phone network, transport company, app or sports club
#     that writers reach for. Write what the thing is instead ("a tin of chocolate drink").
